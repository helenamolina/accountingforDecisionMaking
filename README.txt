    Accounting for Decision Making – Interactive Sequence (Mini-site)
    =================================================================

    How to run locally:
    - Open index.html in a modern browser.
    - Ensure PDFs exist in /assets/pdfs (already copied if provided).
    - Replace 'PASTE_YOUR_KAHOOT_URL_HERE' and 'PASTE_YOUR_QUIZLET_URL_HERE' in index.html with your quiz links.
